Bulk Clip Trimmer

A Windows desktop app for getting through huge piles of gaming clips. I built it to deal with my own.

Get it on the Microsoft StoreView the code

What it does

Keep moving

Trim a clip, send it to the queue and start on the next one while processing happens in the background.

Batch processing

Queue up as many clips as you like and let the app work through them.

Separate outputs

Set different output folders for video and audio exports, with your own quality settings.

Audio extraction

Pull the audio out of a video clip with a single click.

How it works

  1. Step 1

    Set up your output

    Choose where video and audio exports go, along with your default format and quality.

  2. Step 2

    Mark start and end

    Move through the clip and set the start and end points.

  3. Step 3

    Queue and repeat

    Add the clip to the queue and move straight on to the next one.

System requirements

Minimum

  • Windows 10 64-bit
  • 4GB RAM
  • Intel i3, AMD Ryzen 3 or equivalent
  • 100MB of storage
  • 1280x720 display

Recommended

  • Windows 10 or 11 64-bit
  • 8GB RAM
  • Intel i5, AMD Ryzen 5 or better
  • SSD storage
  • 1920x1080 display
